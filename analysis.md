# Analysis

A linked-list stack pushes at the head because adding a new node there takes O(1) time. Popping from the head also takes O(1) time, while removing from the tail of a singly linked list would require searching through the list. An array queue must be circular so that positions freed by dequeue operations can be reused without shifting all the remaining elements. The modulo operator allows the front and rear positions to wrap around to the beginning of the array.
